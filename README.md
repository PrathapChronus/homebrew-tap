# homebrew-tap

Homebrew recipes for Chronus Claude Code plugins, until they move to a ChronusCorp tap.

```
brew tap prathapchronus/tap
brew install prathapchronus/tap/claude-tower
```

| Formula | What it is | Plugin |
| --- | --- | --- |
| `claude-tower` | Claude Tower menu bar app | [session-tower](https://github.com/ChronusCorp/chronus-ai-stack/tree/main/plugins/session-tower) |

Sources are fetched from ChronusCorp repos over HTTPS, so run `gh auth login` and
`gh auth setup-git` first.
